# Salesforce AI Content Framework

A modular Salesforce framework for integrating multiple AI providers
(ChatGPT & Gemini) with model selection support.

## Features
- Multi-provider AI architecture
- Model registry and selection
- Secure callouts via Named Credentials
- Aura-based UI
- Clean Apex layering

## Why This Project
Demonstrates enterprise-level Salesforce development, API integrations,
and scalable architecture.
